# Driver requirements by state: status and official sources (25 Oct 2026)
Policy: Queensland is the only state where DODO takes trips. Other states can register and upload documents but
stay ineligible (multi-state migration 46). A state's requirements are shown on the website only once verified.
The website shows Queensland's list only and tells other states that DODO will confirm theirs.
